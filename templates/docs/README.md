- 作者的预期（为什么做、要达到什么）见 [../user-spec/README.md](../user-spec/README.md)；
- 设计依据见 `../user-spec/decisions/`（`D-NNNN`），说明依据时引用对应的决策。
- 做法改了，在同一次（或紧随其后的）提交里同步更新这里。
- 发现了还没修的毛病，记在受影响那部分技术文档的「已知问题」一节（和有意不做的「已知限制」分开）；修好时删掉，另写修 bug 的决策。
